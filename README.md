## **Analisis Sentimen pada Aplikasi TIX ID di Google Play Store**

- ### File notebook scrapping.ipynb merupakan notebook untuk melakukan scraping ulasan dari apk TIX ID
- ### File notebook analisis_sentimen.ipynb merupakan notebook untuk melakukan proses analisis sentimen dari import library, load data, preprocessing, labeling, spliting, testing, dan training, 
- ### File notebook inference.ipynb merupakan notebook untuk melakukan inference atau testing terhadap model yang sudah dibuat dengan testing set tertinggi.
- ### file requerments.txt berisi library-library yang digunakan.
